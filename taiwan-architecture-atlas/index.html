ABOUT / 003

Making architectural
relationships legible.

臺灣建築知識網絡是可持續增補的研究型數位索引。

01 / THE IDEA

不是排行榜，而是關係網。

本計畫收錄與臺灣建築文化相關的人物、事務所、教育機構及作品，記錄彼此之間可查證的專業關係。收錄與否並不等於重要性的評比；尚未連線也不等於不存在關係。

02 / EVIDENCE

每一條線，都需要證據。

資料應由官方機構、校史、事務所、建築專業媒體或學術研究支持。建築設計、任職、創辦、共同合作與教育關係分開記錄，不以風格相似推定師承或思想影響。

03 / SCOPE

一個刻意有限的起點。

目前的選例重點為戰後至當代的幾組著名建築事件，包含東海大學現代主義建築、公共文化設施、地方實踐及國際合作。這不是臺灣建築史的完整名錄。

04 / CONTRIBUTE

開放校訂與擴充。

歡迎提供可查證的補充、誤植或作品歸屬更正。請在 GitHub 提交 Issue，附上人物／機構名稱、關係類型、具體年月及一手來源。
