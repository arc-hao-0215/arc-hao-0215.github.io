# Gaoligong research field-image assets

This folder supports `research-gaoligong.html`. Eight images are embedded by the research essay; the ninth exhibition photograph is retained as an optional archival image.

Image filenames used by the page:
- 02-tea-house-view.webp — opening
- 06-regional-trail-map.webp / 03-dahaoping-trail-map.webp — historic routes
- 08-field-interview-mapping.webp — tea history / field mapping
- 09-mountain-walk.webp — working forest
- 04-vernacular-materials.webp — existing vernacular construction
- 05-forest-biodiversity.webp — ecological observations
- 01-field-conversation.webp — local tea-house conversation

All photographs and original five-panel compositions must be displayed uncropped. The site hides image slots cleanly until files are available; upload the provided WebP files with these exact names to this folder.
